# Audible Insights

An end-to-end book and audiobook recommendation system built with Python, pandas, scikit-learn, NLP, clustering, and Streamlit.

## What this project does

- Merges the standard and advanced Audible catalog datasets.
- Cleans ratings, review counts, prices, descriptions, listening times, and rank/genre text.
- Produces EDA-ready processed data.
- Builds a content-based recommender using TF-IDF and cosine similarity.
- Builds a genre/description clustering model with K-Means.
- Serves recommendations through a Streamlit interface.
- Includes a hidden-gem ranking that balances rating quality and review volume.

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
python -m src.data_pipeline
python -m src.recommender --build
streamlit run app/streamlit_app.py
```

Open the local Streamlit URL, choose a book, and request similar recommendations.

## Modeling approach

### Content-based recommendations

The recommender combines title, author, description, and extracted genre text into one document. TF-IDF converts the text to sparse features, and cosine similarity ranks books with similar content. A small rating-quality adjustment breaks ties without overwhelming semantic similarity.

### Clustering

K-Means groups books using the same TF-IDF representation. The cluster label is exposed in the processed data and can be inspected in the app.

### Evaluation

This dataset has catalog metadata rather than user-level interaction history, so collaborative-filtering metrics such as RMSE are not valid without a user-item rating matrix. The project therefore reports offline proxy checks: duplicate handling, catalog coverage, recommendation uniqueness, and similarity sanity checks. Add interaction data later to evaluate precision@k, recall@k, and NDCG properly.

## Data notes

The raw files are retained locally in `data/raw/` and are not assumed to be clean. The pipeline is deliberately defensive around sentinel values such as `-1`, malformed rank strings, duplicate book names, and descriptions containing scraping artifacts.

## Optional deployment

The Streamlit app can be deployed on Streamlit Community Cloud, Render, or AWS. For AWS, package the repository with a Python 3.11 runtime and run `streamlit run app/streamlit_app.py --server.address 0.0.0.0` behind the selected service.
